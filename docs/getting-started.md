# はじめての漢字チェック

小学生向けの原稿に、対象学年ではまだ習わない漢字が入っていないか確認したい人のための手順です。
プログラミングの知識は必要ありませんが、最初の準備と原稿の検査には、文字でパソコンを操作する「ターミナル」を使います。

この手順を終えると、テキストファイルまたはMarkdownファイルに対して、次のような結果を表示できます。

```text
原稿.txt
  3:5  error  「植」は小学3年生で学習する漢字です。小学2年生までの文章では使用できません。  ja-grade-kanji
```

textlintは問題の場所を報告するだけで、原稿を自動では書き換えません。
報告を読んで、漢字をひらがなにするか、そのまま使うかを執筆者が判断できます。

## 準備するもの

検査できる原稿は、ファイル名の末尾が `.txt` または `.md` のファイルです。
Microsoft Wordの `.docx` ファイルは直接検査できません。
Wordで執筆している場合は、原稿の複製を「書式なしテキスト（`.txt`）」として保存してから検査してください。

検査の仕組みを動かすために、**Node.js**というソフトウェアも使います。
Node.jsは最初に一度インストールすれば、原稿を検査するたびに入れ直す必要はありません。

## Node.jsをインストールする

[Node.jsの公式サイト](https://nodejs.org/ja)を開き、LTSと表示された版をダウンロードしてインストールします。
このルールを使うには、Node.js 20以上が必要です。
インストーラーの選択肢は、特別な理由がなければ初期設定のまま進めてください。

インストールが終わったら、Windowsでは「PowerShell」、macOSでは「ターミナル」を開きます。
以後、この画面をまとめて「ターミナル」と呼びます。

次の2行を1行ずつ入力し、そのたびにEnterキーを押します。

```shell
node --version
npm --version
```

それぞれにバージョン番号が表示されれば、Node.jsの準備は完了です。
`node`または`npm`が見つからないという内容が表示された場合は、いったんターミナルを閉じて開き直してください。

## 原稿を検査するフォルダーを作る

原稿と設定をまとめる専用フォルダーを作ります。
ターミナルで次の3行を順番に実行してください。

```shell
mkdir kanji-check
cd kanji-check
npm init -y
```

`kanji-check`がフォルダー名です。
別の名前にしたい場合は、最初の2行にある`kanji-check`を同じ名前に置き換えます。

最後のコマンドによって、`package.json`という管理用ファイルが作られます。
このファイルを自分で編集する必要はありません。

## textlintと漢字チェックをインストールする

漢字チェックは、誰でもインストールできる[npmの公開パッケージ](https://www.npmjs.com/package/textlint-rule-ja-grade-kanji)として配布しています。
`kanji-check`フォルダーにいる状態で、次のコマンドを実行します。

```shell
npm install --save-dev textlint textlint-rule-ja-grade-kanji
```

処理には少し時間がかかることがあります。
ターミナルに再び文字を入力できる状態になり、`npm error`で始まる表示がなければインストールは完了です。

この処理によって、`node_modules`フォルダーと複数の管理用ファイルが作られます。
通常は中身を確認したり編集したりする必要はありません。

## 検査する学年を設定する

次のコマンドで、textlintの設定ファイルを作ります。

```shell
npx textlint --init
```

`kanji-check`フォルダーに`.textlintrc.json`が作られます。
先頭が`.`のファイルは、環境によって通常の一覧に表示されないことがあります。

`.textlintrc.json`をテキストエディターで開き、中身をすべて次の内容に置き換えます。
この例では、小学2年生までに習う漢字を許可します。

```json
{
  "rules": {
    "ja-grade-kanji": {
      "grade": 2
    }
  }
}
```

対象学年を変えるには、`grade`の数値を`1`から`6`までの整数に変更します。
たとえば小学4年生向けの原稿なら、`"grade": 4`と指定します。

この設定ファイルには、コメントや末尾の余分なカンマを書けません。
設定エラーが出た場合は、まず上の内容をそのまま貼り直してください。

## 原稿を検査する

検査する`.txt`または`.md`ファイルを、`kanji-check`フォルダーへコピーします。
ここでは、ファイル名を`原稿.txt`とします。

ターミナルで次のコマンドを実行します。

```shell
npx textlint "原稿.txt"
```

ファイル名に空白が含まれていても扱えるように、ファイル名は`"`で囲んでください。

対象学年では習わない漢字があると、ファイル名、行番号、列番号、理由が表示されます。

```text
原稿.txt
  3:5  error  「植」は小学3年生で学習する漢字です。小学2年生までの文章では使用できません。  ja-grade-kanji
```

この例の`3:5`は、3行目の5文字目付近に問題があることを示します。
原稿を直して保存したあと、同じコマンドをもう一度実行してください。
ターミナルで上矢印キーを押すと、直前のコマンドを呼び出せます。

何も表示されずに次の入力を受け付ける状態へ戻れば、検出対象の漢字はありません。
ただし、文章の難しさや読みやすさまで保証するものではないため、最後は対象読者に合わせて原稿を読み直してください。

## 複数の原稿をまとめて検査する

同じフォルダーにあるすべての`.txt`ファイルと`.md`ファイルを検査するには、次のコマンドを使います。

```shell
npx textlint "*.txt" "*.md"
```

原稿を子フォルダーにも分けている場合は、次のコマンドでその中まで検査できます。

```shell
npx textlint "**/*.txt" "**/*.md"
```

## 固有名詞などを例外として許可する

人名や地名など、対象学年外でも原稿に必要な漢字は、`allow`へ登録できます。
次の設定は、小学2年生までの漢字に加えて「誰」「情」「報」を許可します。

```json
{
  "rules": {
    "ja-grade-kanji": {
      "grade": 2,
      "allow": ["誰", "情報"]
    }
  }
}
```

`"情報"`のように複数の文字をまとめて書くと、その中の漢字を1文字ずつ許可します。
登録した語だけを例外にする設定ではないため、「情」と「報」は別の語に含まれていても許可されます。

## よくあるエラー

### `npm error 404 Not Found`と表示される

インストール先として使っているサーバーに、パッケージが見つからないときの表示です。
コマンドが次の内容と一致しているか確認してください。

```shell
npm install --save-dev textlint textlint-rule-ja-grade-kanji
```

名前が一致している場合は、npmの公式サーバーを指定してもう一度インストールします。

```shell
npm install --save-dev textlint textlint-rule-ja-grade-kanji --registry=https://registry.npmjs.org/
```

職場や学校のネットワークでは、利用できるソフトウェアを管理するために別のサーバーを経由していることがあります。
公式サーバーを指定しても失敗する場合は、ネットワークの管理者へnpmからのインストールが許可されているか確認してください。

### `node`または`npm`が見つからない

Node.jsをインストールしたあと、開いたままのターミナルには設定が反映されないことがあります。
ターミナルを閉じて開き直し、`node --version`を再実行してください。

### `Cannot find module`またはルールが見つからないと表示される

ターミナルが`kanji-check`以外のフォルダーを開いているか、インストールが完了していません。
次のコマンドを順番に実行してから、原稿を再検査してください。

```shell
cd kanji-check
npm install
```

### 設定ファイルを読み込めない

ファイル名が`.textlintrc.json.txt`になっていないか確認してください。
Windowsのメモ帳で保存する場合は、ファイルの種類に「すべてのファイル」を選び、`.textlintrc.json`という名前で保存します。

ファイル名が正しければ、設定内容の引用符、波括弧、カンマを確認します。
原因がわからない場合は、「検査する学年を設定する」に掲載した設定例へいったん戻してください。

### 原稿が見つからないと表示される

原稿が`kanji-check`フォルダーにあるか、コマンドに書いたファイル名と実際の名前が一致しているか確認します。
`.txt`や`.md`まで含めて同じ名前にしてください。

### 警告が多すぎる

`grade`が原稿の対象学年と一致しているか確認します。
固有名詞など意図して使う漢字は、理由を確認したうえで`allow`へ登録してください。
大量の漢字をまとめて許可すると、本来見つけたい未習漢字まで見逃すため、必要な文字だけを登録します。

## 次回からの使い方

初回の準備が終われば、次回から必要な操作は次の4つです。

1. ターミナルを開く。
2. `cd kanji-check`を実行する。
3. 原稿を`kanji-check`フォルダーへ入れる。
4. `npx textlint "原稿.txt"`を実行する。

対象学年を変えるときだけ、`.textlintrc.json`の`grade`を変更します。
